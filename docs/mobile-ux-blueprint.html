Direction

Calm, colourful where it means something, one tap to the next step.

Three destinations — Ask, Library, Manage. Every screen has one obvious primary action in the brand violet; everything else is quieter, in a sheet, or one level deeper.

1
One primary action per screenThe violet button, FAB or send arrow is always the next step. Secondary actions are grey; rare and destructive ones live in “···”.
2
Colour carries meaningViolet = action and current place. Tone tiles identify a collection or file type, the same colours as web. Green/amber/red only beside a status word.
3
Thumb-firstPrimary actions sit at the bottom (composer, FAB, sticky bar, sheet buttons). 44pt targets, sheets instead of dialogs, no hidden gestures required.
