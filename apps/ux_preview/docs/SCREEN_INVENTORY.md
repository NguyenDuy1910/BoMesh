# BoMesh screen inventory

Routes are hash routes (`ux-preview.html#/knowledge`). **Primary** is the one dominant action; secondary actions live in toolbars, row menus and drawers. Every list/table screen supports forced Loading, Empty and Error states via `gate()`.

Applies everywhere ([PRODUCT_DESIGN_RULES.md](../PRODUCT_DESIGN_RULES.md), action system in [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md#rules)): one primary per region; list search, sort, filters and bulk selection appear only when a list has 7+ items or one of them is in use (`needsTools`); pagination only when there is more than one page; counts appear once (tab badge or list header, not both); the whole row opens its object and row-level secondary actions show on hover/focus (always on touch); reversible changes apply at once with Undo, only irreversible or high-risk ones confirm; at most one side panel is open at a time.

## Acceptance per route

1. Direct hash navigation renders from `file://`.
2. Sidebar, the top-row trail, palette and in-page links reach the same route.
3. Unpermitted routes show a no-access state without data.
4. Loading, Empty and Error can be forced; no-results can be cleared.
5. The primary action changes local data before its toast.
6. Overlays close with their close action and Escape; focus returns to the trigger.
7. Usable in light and dark at 1440, 1024, 834 and 390 px.
